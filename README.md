# 네온 스네이크 (NeonSnake)

클래식 스네이크에 사이버펑크 비주얼과 아케이드 요소를 더한 브라우저 게임입니다. 키보드와 터치 조작을 지원하며, 네 가지 게임 모드와 특수 아이템, 스킨, 콤보, 업적을 제공합니다. 설정과 플레이 기록은 브라우저의 `localStorage`에 저장됩니다.

## 주요 기능

- **게임 모드:** 클래식, 아케이드(특수 아이템), 장애물, 타임 어택
- **난이도:** 쉬움, 보통, 어려움, 익스트림
- **아이템:** 일반 사과, 황금 사과, 속도 부스트, 감속, 몸 길이 감소, 자석
- **콤보와 기록:** 연속으로 먹으면 최대 5배 점수 콤보가 적용되고, 모드별 최고 점수와 업적을 기록합니다.
- **조작:** 방향키 또는 WASD, 화면 스와이프, 가상 방향 패드
- **설정:** 스킨, 효과음, 진동, 터치 패드 표시, 벽 통과 여부
- **반응형 캔버스:** 화면 크기에 맞춰 게임 보드 크기를 조절합니다.

## 시작하기

Node.js와 npm이 설치되어 있어야 합니다.

```bash
npm install
npm run dev
```

개발 서버는 포트 `3000`에서 실행됩니다. 터미널에 표시되는 로컬 주소를 브라우저에서 여세요.

프로덕션 빌드와 빌드 결과 미리보기:

```bash
npm run build
npm run preview
```

TypeScript 검사:

```bash
npm run lint
```

테스트 실행용 npm 스크립트는 현재 정의되어 있지 않습니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 방향키 또는 `W` `A` `S` `D` | 이동 방향 변경 |
| `Space` | 일시 정지 또는 재개 |
| `R` | 새 게임 시작 |
| `Escape` | 열린 설정·기록·도움말 창 닫기 |
| 터치 패드 또는 게임 보드 스와이프 | 모바일 방향 조작 |

뱀은 정반대 방향으로 즉시 회전할 수 없습니다. 일시 정지 중 방향을 입력하면 게임이 재개됩니다. 벽 통과 설정이 켜져 있으면 보드 반대편으로 이어지고, 꺼져 있으면 벽 충돌로 게임이 끝납니다.

## 게임 모드와 아이템

- **클래식:** 기본 생존 모드입니다.
- **아케이드:** 주기적으로 특수 아이템이 등장합니다.
- **장애물:** 보드의 고정 장애물과 충돌하지 않도록 이동합니다.
- **타임 어택:** 60초 제한 시간 동안 점수를 얻고, 아이템을 먹어 남은 시간을 늘립니다.

일반 사과는 10점, 황금 사과는 50점입니다. 속도 부스트는 20점과 함께 잠시 이동 속도를 높이고 점수 배율을 두 배로 적용합니다. 냉동 베리는 20점과 함께 잠시 이동 속도를 낮춥니다. 다이어트 버섯은 25점과 함께 뱀의 길이를 줄이고, 자석은 20점과 함께 가까운 아이템을 끌어당깁니다. 특수 아이템은 일정 시간이 지나면 사라질 수 있습니다. 콤보와 속도 부스트가 적용되면 획득 점수도 함께 증가합니다.

## 기술 스택

- React 19 및 TypeScript
- Vite 8
- Tailwind CSS 4
- HTML Canvas 2D를 이용한 게임 보드 렌더링
- Lucide React 아이콘, Web Audio API 효과음

## 프로젝트 구조

```text
src/
├── App.tsx                 # 게임 상태와 규칙, 입력 및 화면 조립
├── main.tsx                # React 앱 진입점
├── index.css               # 전역 스타일과 Tailwind CSS
├── components/             # 보드, HUD, 터치 조작, 모달 UI
├── types/game.ts           # 게임 상태 및 설정 타입
└── utils/
    ├── gameConstants.ts    # 보드·난이도·스킨·업적 설정
    ├── storage.ts          # localStorage 설정 및 기록 저장
    └── audio.ts            # Web Audio API 효과음
```

`App.tsx`가 게임 루프와 충돌 판정, 점수·콤보·아이템·기록 상태를 관리합니다. `GameBoard.tsx`는 Canvas에 보드와 게임 요소를 그리며, `components/`의 나머지 UI는 상태를 표시하거나 사용자 입력을 전달합니다. 설정과 통계는 `storage.ts`를 통해 브라우저에 저장됩니다.
